# Профиль игрока
Консольная программа на Python: три игрока, у каждого имя, здоровье и очки. Данные хранятся в словарях, игроки лежат в списке players.

## Запуск
python player_profile.py

## Возможности

- выбор одного из трёх игроков (Дима, Саня, Арман);
- показать профиль;
- добавить очки;
- нанести урон (здоровье не опускается ниже 0);
- защита от неверного ввода: буквы, отрицательные числа, неизвестная команда.

## Функции

- show_player(player) — выводит имя, здоровье и очки;
- add_score(player, points) — добавляет очки;
- take_damage(player, damage) — уменьшает здоровье;
- read_int(text) — читает целое число из ввода;
- show_leaders() — выводит лидеров по очкам;
- game(player) — меню выбранного игрока;
- menu() — главное меню.
